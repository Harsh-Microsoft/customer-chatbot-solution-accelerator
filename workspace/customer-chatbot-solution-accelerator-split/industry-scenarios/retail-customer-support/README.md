# Retail Customer Support

This industry scenario supplies the Contoso Paints catalog CSV, paint policy documents, agent instructions, localized image assets, and a scenario manifest for the `chat-with-data-voice` technical pattern.

It composes with the pattern as a retail product-support pack: the manifest provides the host, welcome, catalog, and presentation configuration; the CSV and policy corpus provide the grounding data; and the `assets/` folder supplies the scenario-local product images used by the catalog cards.
